# TaskFlow — Smart Task Management App

A Python-based task management application built with Streamlit to help users organize tasks, manage priorities, set deadlines, and track progress through an interactive dashboard.

## Features

- **Task Management:** Add, edit, complete, and delete tasks.
- **Priority Management:** Organize tasks by High, Medium, and Low priority.
- **Deadline Tracking:** Set optional due dates and identify overdue tasks.
- **Search & Filtering:** Search tasks by title and filter them by priority.
- **Progress Dashboard:** Monitor total, pending, completed, and overdue tasks.
- **Task Statistics:** View task completion progress and priority distribution.
- **Custom Themes:** Choose from Sea Green, Navy Blue, and Dark Theme.
- **Local Data Storage:** Save and load tasks using JSON.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/amna-badar-tech/TaskFlow.git
cd TaskFlow
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the application

```bash
streamlit run streamlit_app.py
```
